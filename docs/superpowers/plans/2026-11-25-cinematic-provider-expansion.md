# ATLAS V0.5.2 implementation sequence

1. Establish a fresh V0.5.1 regression baseline and verify the provider contracts. Pilot existing Poly Haven downloads from architecture and nature categories before extending the importer.
2. Extend Poly Haven metadata and preflight quality variants, keep asset approvals in the existing registry, and enforce a configurable source cache budget. Run focused acquisition fixtures and test real selected downloads with Blender.
3. Add bounded Sketchfab public discovery and licensed, authorized downloads. Keep signed download URLs and credentials out of persisted data. Add the supported Blendkit manual handoff and static native Blender conversion with separate safety checks.
4. Join catalog metadata with local inspection evidence for deterministic selection. Keep historically suggestive metadata, verified production readiness and license rights distinct.
5. Assemble reusable woodland and fort scenes from acquired geometry. Render ordinary ATLAS previews, compare actual frames with V0.5.1, and retain provenance and inspection evidence.
6. Run complete available regressions and document authentication gaps and measured acquisition and render results. Publish verified commits to `main`.
