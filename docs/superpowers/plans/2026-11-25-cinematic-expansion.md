# ATLAS V0.5.1 implementation sequence

1. Run the published V0.5 regression suite with Blender, Turbo, Rhubarb and acquired assets enabled.
2. Prove the pinned upstream MPFB extension can generate an anatomically varied, clothed, skinned human in background Blender. Pin official face, viseme and wardrobe data.
3. Export and validate an embedded human GLB. Exercise independent face keys and compatible embedded body actions after reopening a saved scene.
4. Acquire and inspect real photogrammetry and historical geometry. Pin texture channels and environment images and preserve source notices.
5. Run the normal pipeline with preview, realistic and cinematic settings. Inspect frames for framing, opacity, fit, jaw, blinking, body motion and audio timing.
6. Record results, run regressions, package the engine and publish verified commits to GitHub main. Report scope gaps against the requested targets.
