# ATLAS V0.6 human motion

1. Audit saved KayKit and MPFB rig reports, sample the source walk in Blender, and establish the V0.5.2 regression baseline.
2. Bake licensed source clips onto the exact MPFB rest skeleton using canonical rest-space rotations. Store immutable, fingerprinted motion records and measure root displacement, stride and shoe height. Exercise cached playback through the Blender worker.
3. Extend schema 1.5 with pinned motions, flat routes, blend windows and approach actions using existing actor/transform models. Validate paths, scene timing, simultaneous footprints and target compatibility before Blender.
4. Render inexpensive movement, multi-character, and speech previews, inspect saved Actions and actual frames, compare ground contact and report the limits of the supported rig slice.
5. Verify the existing integrations and package, document exact source, motion and scene pins, and publish each verified checkpoint to GitHub main.
