# ATLAS Director Infrastructure Implementation Plan

**Goal** — Make ATLAS production capabilities discoverable and executable by a model-independent director, beginning with a verified two-actor handoff.

**Architecture** — Creative intent is versioned data. Shared host services validate and resolve production requests before Blender executes the resulting project. The CLI exposes those services now. Future HTTP, MCP and studio surfaces can reuse the same contracts.

1. Establish the V0.6 baseline. Add typed preflight, action compilation and preview operations, a creative-plan intake contract, and JSON capability discovery. Test legacy CLI compatibility, unsupported requirements, strict request fields and render limits.
2. Add named prop and hand anchors. Validate ownership and timing on the host, then use the editable Blender rig and evaluated contact targets to verify one exchange with measured world-space continuity. Reuse the two MPFB actors and fort dialogue.
3. Improve walk contact with a measured before-and-after fixture. Preserve the path and arrival frame while measuring the remaining slide, penetration and pose changes. Keep running flight separate.
4. Add procedural worlds and persistent scene state. Verify two distinct layouts with declared anchors, clearances and reusable asset pins.
5. Add shot staging, camera and lighting controls, a multi-shot timeline and continuity validation. Verify a conversation with coverage.
6. Expose the established services through a Director API and bounded MCP tools. Validate input, permissions and artifact access for each operation.
7. Add model-independent creative-plan compilation, production feedback and rebuild scope. Verify one cinematic short and one independent educational production.
8. Add render orchestration, assembly and recovery, then the studio interface. Verify revision, regeneration and export through normal user workflows.

Keep earlier project schemas working. Keep downloaded sources, private credentials and production outputs local. Record the exact tests, artifact and limitations at each push to GitHub main.
